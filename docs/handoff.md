### מה יש באפליקציה עכשיו
- **שני מצבים נפרדים:**
  - **הדגמה** — כל מה שהיה, עם אנשים מדומים.
  - **בדיקה אמיתית** — חברים אמיתיים.
  - מחליפים בהגדרות. קישור הזמנה עובר למצב האמיתי לבד.
- **כניסה עם שם בלבד.** מספר טלפון הוא רשות.
- **הזמן חבר:** מסך השיתוף של הטלפון, עם ההודעה שביקשת וקישור.
  - בלי דף הזמנה: ההודעה כוללת קישור הורדה וקוד.
  - "יש לי קוד הזמנה": אפשר להדביק את כל ההודעה.
- **פנויים עכשיו:** רואים אילו חברים פנויים. הזמינות נגמרת לבד.
- **הצעה הדדית:** מסך מלא "יוני פנוי עכשיו. רוצה לדבר?" עם "דבר עכשיו" / "לא עכשיו".
  - "מחכים ליוני…" עד שהוא עונה.
  - אם לא הסתדר: "לא הסתדר הפעם. נחפש הזדמנות אחרת."
- **כששניכם אמרתם כן:**
  - אם החבר שיתף מספר: שיחת טלפון רגילה, ספירה של 3 שניות עם ביטול, ורק צד אחד מחייג.
  - אחרת: שיחה מדומה.
  - אחר כך: "שמח שדיברתם?"
- **בנסיעה:** מסך כהה עם כפתורים ענקיים. ההצעה מוקראת בקול, ואפשר לענות "כן"/"לא". השאלה אחרי השיחה מחכה לסוף הנסיעה.
- **לשונית "בדיקה":**
  - מצבים: שרת, חשבון, עדכון מיידי, חברים, זמינות, הצעה אחרונה, גרסה, שגיאה.
  - כפתור "העתק מידע לבדיקה", בלי סודות.
- **חסימה, דיווח והסרה** מתוך "האנשים שלי".
- **דף הזמנה** (`invite_site/`): הורדה, "פתיחה באפליקציה", והקוד להעתקה. מתפרסם אוטומטית לענף `gh-pages`.

## מה הבעלים צריך לעשות (פעם אחת, כ-25 דקות)
לפי `docs/setup-guide.md`:
1. שני סודות חתימה ב-GitHub, אם עוד לא הוספו.
2. פרויקט Supabase חינמי:
   - להדביק את קובץ ה-SQL ולהריץ.
   - להפעיל כניסה אנונימית.
   - להוסיף ל-GitHub Variables את `SUPABASE_URL` ו-`SUPABASE_ANON_KEY`.
3. GitHub Pages מענף `gh-pages`, ואז להוסיף Variable בשם `INVITE_BASE_URL`.
4. בנייה מחדש (Actions ‹ Run workflow).
5. להסיר את הגרסה הישנה פעם אחת ולהתקין מחדש.

## מגבלות ידועות
- אין Push. בזמן הבדיקה שתי האפליקציות צריכות להיות פתוחות.
- פרויקט Supabase חינמי נרדם אחרי 7 ימים בלי שימוש. מעירים אותו ב-Restore.
- ב-GitHub Pages הקישור פותח קודם דף, ואז לוחצים "פתיחה באפליקציה". ב-Cloudflare (רשות) הקישור נפתח ישר באפליקציה.
- מחיקת האפליקציה = משתמש חדש (כניסה עם שם בלבד).
- iPhone: עדיין לא.

## הערות טכניות לממשיך
- branch: `claude/social-voice-app-mnrxc1`.
- Flutter 3.47.6 ב-`/opt/sdk/flutter` (לא נשמר בין sessions).
- Supabase מקומי:
  - מפעילים קודם את `dockerd`.
  - `SUPABASE_INTERNAL_IMAGE_REGISTRY=docker.io supabase start -x studio,imgproxy,edge-runtime,logflare,vector,mailpit,postgres-meta,supavisor` (ה-CLI נמצא ב-`/opt/supa`).
  - `supabase db reset` מריץ את ה-migration מחדש. (Storage מופעל ב-config.toml בשביל התמונות.)
- בדיקת שרת:
  - `cd tool/e2e && SUPABASE_ANON_KEY=<local publishable> dart run bin/e2e.dart`
  - `SUPABASE_LIVE_URL=http://127.0.0.1:54321 SUPABASE_LIVE_KEY=<local publishable> flutter test test/supabase_live_test.dart`
- ה-APK נבנה רק ב-GitHub Actions, כי כלי Android חסומים בענן.
- הבחירה בין דמו לאמיתי: `appModeProvider` ב-`lib/real/real_controller.dart`. ההגדרות מגיעות מ-`--dart-define` (`lib/real/backend_config.dart`).
