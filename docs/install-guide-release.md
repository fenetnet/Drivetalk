## איך מתקינים את DriveTalk (אנדרואיד)

**1. להוריד:** בתחתית הדף, תחת **Assets**, ללחוץ על **drivetalk-prototype.apk**.

**2. לפתוח את הקובץ שירד.** בדרך כלל מהודעת ההורדה למעלה, או מאפליקציית "קבצים" ← הורדות.

**3. אם הטלפון מבקש אישור "להתקין אפליקציות לא מוכרות":**
- לוחצים **הגדרות** ← מדליקים **"אפשר מהמקור הזה"** ← חוזרים אחורה ← **התקנה**.
- **סמסונג:** הגדרות ← אפליקציות ← Chrome (או "הקבצים שלי") ← "התקנת יישומים לא ידועים" ← להדליק.
- **שיאומי:** אם מופיע "אבטחה" ← לאשר ← **להמשיך בהתקנה**.

**4. אם מופיעה אזהרה של Google Play Protect:**
- **"אפליקציה לא מוכרת" / "נחסם על ידי Play Protect":** לוחצים **"פרטים נוספים"** ← **"התקנה בכל זאת"**.
- **אם מוצעת "סריקה":** אפשר ללחוץ "סריקה". זה לוקח כמה שניות, ואז "התקנה".

**5. סיימנו.** פותחים את DriveTalk.
- **גרסאות חדשות:** האפליקציה תודיע בעצמה שיש גרסה חדשה. לוחצים "לעדכן".
- **מה נשמר:** החברים וההגדרות נשארים.

זו גרסת ניסיון שמחוץ לחנות, ולכן הטלפון מזהיר. בהמשך היא תהיה ב-Google Play.
