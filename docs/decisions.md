# יומן החלטות

כל החלטה משמעותית נרשמת כאן: מה הוחלט, למה, ומה המשמעות למשתמש.
סטטוס: ✅ מאושר · 🟡 מוצע, ממתין לאישור

---

## D-001 — Flutter כטכנולוגיה לאפליקציה ✅
**הוחלט:** קוד אחד ל-Android ובהמשך ל-iPhone.
**למה:** חוסך כתיבה כפולה; תמיכה טובה בעברית/RTL; גישה לשירותי מכשיר דרך "גשרים" קטנים.
**למשתמש:** אותה חוויה בשני הטלפונים.

## D-002 — Phase 1 בלי שרת ובלי שירותים חיצוניים ✅
**הוחלט:** ה-prototype רץ כולו בטלפון עם 12+ משתמשים מדומים.
**למה:** לבדוק את החוויה לפני שמשקיעים בתשתית ובעלויות.
**למשתמש:** אפשר לנסות את כל הזרימה עכשיו, אבל לא לדבר עם אנשים אמיתיים.

## D-003 — שכבות נפרדות ושירותים "מזויפים" שניתנים להחלפה ✅
**הוחלט:** המסכים מדברים רק עם "ממשקים". בשלב הראשון מאחוריהם נתונים מדומים.
**למה:** בהמשך מחליפים ל-Supabase/LiveKit בלי לבנות את המסכים מחדש.

## D-004 — מנוע התאמה מבוסס כללים, עם משקלים בקובץ הגדרות ✅
**הוחלט:** בלי AI. סינון → ניקוד → בחירה (עם אחוז הפתעה) → הסבר.
**למה:** שקוף, צפוי, אפשר להסביר כל הצעה ולכוונן בלי לשנות קוד.

## D-005 — הסברים להצעה נבנים רק מנתונים אמיתיים ✅
**הוחלט:** כל "סיבה" היא שדה מובנה (למשל "מספר חברים משותפים = 3"), והטקסט נוצר ממנו.
**למה:** כך אי אפשר "להמציא" סיבה.

## D-006 — Riverpod לניהול מצב 🟡
**מוצע:** ספרייה נפוצה ומתוחזקת ב-Flutter שמאפשרת להחליף בקלות שירות מזויף בשירות אמיתי.
**למשתמש:** אין השפעה ישירה; משפיע על מהירות ואמינות הפיתוח.

## D-007 — עברית כשפת ברירת מחדל, כל הטקסטים בקבצי תרגום ✅
**למה:** RTL מלא מהיום הראשון; אנגלית תתווסף בלי לגעת במסכים.

## D-008 — זיהוי נסיעה: API רשמי בלבד, בלי GPS רציף ✅
**הוחלט:** Android — Activity Recognition Transition API (+ Bluetooth רכב אופציונלי).
iPhone — App Intents + Shortcuts (Driving Focus / CarPlay). לא ייבנה ב-Phase 1.
**למה:** פרטיות וחיסכון בסוללה; עמידה בכללי החנויות.

## D-009 — Supabase כ-backend ו-LiveKit לשיחות — כיוון מועדף, לא מחובר 🟡
**הערה:** לפני חיבור יוצג לבעלים הסבר מלא על עלויות, חינם וחלופות, וההחלטה תתועד כאן.

## D-010 — עבודה ב-branch ייעודי לפני main ✅
**הוחלט:** הפיתוח נעשה ב-branch `claude/social-voice-app-mnrxc1`. מיזוג ל-main אחרי בדיקה ובאישור.
**למה:** כך תמיד יש ב-main גרסה שעובדת.
