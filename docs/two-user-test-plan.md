# תוכנית בדיקה עם שני אנשים

**לפני שמתחילים:** צריך להשלים את `docs/setup-guide.md` (פעם אחת).

**מה צריך:**
- שני טלפוני Android.
- **שתי האפליקציות פתוחות** בזמן הבדיקה. עדיין אין התראות (Push), אז אפליקציה סגורה לא "שומעת" הצעות. כשפותחים אותה, היא מתעדכנת מיד.

**אם משהו לא עובד:** לשונית **בדיקה** ‹ **העתק מידע לבדיקה** ‹ לשלוח לי עם צילום מסך. בטקסט אין סיסמאות, מפתחות, מספרי טלפון או קודי הזמנה.

סימון: ✅ עבד · ❌ לא עבד (לכתוב מה ראיתם)
