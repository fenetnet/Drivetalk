# תוכנית בדיקה עם שני אנשים

_מתייחס ל-Phase 2. ייכנס לשימוש אחרי שהשלב ייבנה._

**מה צריך:** שני טלפוני Android, ואת "בדיקה עם חבר" פתוח אצל שניכם.
**אם משהו לא עובד:** צלמו את מסך "בדיקה עם חבר", לחצו "העתק מידע לבדיקה" ושלחו לי את הצילום ואת הטקסט שהועתק.

סימון: ✅ עבד · ❌ לא עבד (לכתוב מה ראיתם)
